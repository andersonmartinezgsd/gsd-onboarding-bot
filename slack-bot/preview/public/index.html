🔑 Dónde obtener las credenciales

Slack — Obligatorio
SLACK_BOT_TOKEN
Token del bot para enviar mensajes y llamar a la API
1. api.slack.com/apps → Create New App
2. Pegar el manifest.json (ver abajo)
3. OAuth & Permissions → Install App
4. Copiar Bot User OAuth Token
xoxb-123456789-...
SLACK_SIGNING_SECRET
Verifica que los eventos vienen de Slack
api.slack.com/apps → tu app → Basic Information → App Credentials → Signing Secret
abc123def456...
SLACK_APP_TOKEN
Para Socket Mode (dev sin URL pública)
Basic Information → App-Level Tokens → Generate Token → scope: connections:write
xapp-1-A0123...
HR_CHANNEL_ID
Canal donde el bot postea los trackers
En Slack: clic derecho al canal → Copy link
El ID es el último segmento: .../C0ABC1234
C0HR000000
Google Workspace — Recomendado
GOOGLE_CLIENT_EMAIL opcional
Service account para crear cuentas y Drive
GCP Console → Service Accounts → Create → Descargar JSON key
Luego en Google Admin → Domain-wide delegation
sa@project.iam.gserviceaccount.com
GOOGLE_CUSTOMER_ID solo para Voice
Google Admin → Account Settings → Profile → Customer ID
C0abcde12
Time Doctor — Opcional
TIMEDOCTOR_ACCESS_TOKEN opcional
Time Doctor → Settings → Integrations → API → Generate Token

HubSpot — Opcional
HUBSPOT_ACCESS_TOKEN opcional
HubSpot → Settings → Integrations → Private Apps → Create → Scopes: settings.users.write, crm.objects.contacts.write

scalefusion.com → Dashboard → Settings → API → Generate API Key
Necesitas plan Business o superior para acceso API.
